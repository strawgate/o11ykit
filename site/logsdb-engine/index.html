How log storage works: Each service gets its own stream. Within a stream, logs are batched into chunks of ~1024 records. Drain template extraction finds repeating patterns and stores variable slots in typed columnar encodings — for compact log storage with chunk-level summaries and typed columns.

How log analysis works: The engine queries chunks using zone-map pruning — each chunk header stores severity and time ranges. Chunks that can't match are skipped without decoding, reducing query work on larger log datasets.
